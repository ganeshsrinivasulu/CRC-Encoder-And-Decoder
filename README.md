# CRC Encoder and Decoder - Verilog

Verilog implementation of Cyclic Redundancy Check (CRC) Encoder and Decoder.

## Files
- `CRC_Encoder.v` - CRC Encoder module
- `CRC_Decoder.v` - CRC Decoder module

## Features
- Error detection using CRC
- Implemented in Verilog HDL
- Tested with testbench

## Tool
- Vivado / Xilinx ISE
- Verilog HDL

1. Open in Vivado
2. Add source files
3. Run simulationREA
